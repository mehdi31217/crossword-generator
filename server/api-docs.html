🔌 WebSocket — ws://localhost:4000

برای قابلیت‌های بلادرنگ: حضور آنلاین، تایپ کردن، و اتاق‌های مولتی‌پلیر

WS → channel:join ورود به یک کانال (اتاق) 
JSON{
  "type": "channel:join",
  "channel": "global_social",
  "data": {
    "userId": "abc123",
    "name": "مهدی",
    "avatar": "🦊"
  }
}
WS → channel:broadcast ارسال رویداد به همه اعضای کانال 
JSON{
  "type": "channel:broadcast",
  "channel": "room_123456",
  "event": "start_game",
  "payload": { "grid": [...], "clues": {...} },
  "senderId": "abc123"
}
← WS presence_sync بروزرسانی لیست افراد آنلاین در کانال (دریافتی از سرور) 
JSON{
  "type": "presence_sync",
  "channel": "global_social",
  "users": [
    { "userId": "def456", "name": "مهسا", "avatar": "👾" }
  ]
}
← WS channel:event رویداد دریافتی از کانال (broadcast از کاربر دیگر) 
JSON{
  "type": "channel:event",
  "channel": "room_123456",
  "event": "progress",
  "payload": { "id": "def456", "progress": 50 },
  "senderId": "def456"
}
