# قوانین باز شدن دسته‌بندی و سایز

## دو مسیره: امتیاز (Casual) vs لیگ (Battle)

### مسیر اول - امتیاز (score)
**اعمال در:** Casual solo, دعوت دوست به نبرد, چالش با بازیکن آنلاین (غیر Quick Match)

**باز شدن سایز:** با امتیاز کل (score)
| سایز | امتیاز لازم |
|------|------------|
| ۵ | ۰ |
| ۶ | ۱,۵۰۰ |
| ۷ | ۵,۰۰۰ |
| ۸ | ۱۲,۰۰۰ |
| ۹ | ۲۵,۰۰۰ |
| ۱۰ | ۵۰,۰۰۰ |

**باز شدن دسته‌بندی:** با امتیاز کل (score)
| امتیاز | دسته‌های باز |
|:------:|:-----------:|
| ۰ | knowledge, food, all |
| ۵,۰۰۰ | + movies, cities |
| ۱۲,۰۰۰ | + body, jobs |
| ۲۵,۰۰۰ | + tech, nature |
| ۵۰,۰۰۰ | + history, sports, art |

> هر پلهٔ دسته دقیقاً با یک پلهٔ سایز هم‌امتیاز است تا نردبان «هدف بعدی» منو
> پنج پلهٔ تمیز بماند. آینهٔ سروری: `DUEL_SIZE_UNLOCK` / `DUEL_CATEGORY_UNLOCK`
> در `server/index.js` — هر تغییری باید در هر سه جا (این فایل، `utils/config.ts`، سرور) اعمال شود.

### مسیر دوم - لیگ (trophies)
**اعمال در:** Quick Match / Battle mode (مسابقه سریع)

**بدون تغییر:** سایز و دسته بر اساس لیگ باز می‌شوند
- هرچه لیگ بالاتر، دسته‌های بیشتری اجباری می‌شوند
- بازیکن برای بالا رفتن از نردبان لیگ باید با سوالات متنوع‌تر کنار بیاید

### قوانین UI
1. اگر کاربر روی دسته یا سایز قفل‌شده کلیک کند، دیالوگی نمایش داده شود که:
   - امتیاز لازم برای باز شدن را نشان دهد
   - چه دسته‌های دیگری با آن threshold باز می‌شوند
   - مشابه نمایش لیگ‌ها که مشخص است چه چیزی در هر لیگ باز می‌شود

2. در حالت دعوت دوست / چالش با بازیکن آنلاین:
   - محدودیت‌های سایز و دسته از سیستم امتیاز (مسیر اول) پیروی می‌کند
   - محدودیت‌های لیگ (مسیر دوم) فقط برای Quick Match / Battle است

3. در حالت قبول دعوت (طرف مقابل):
   - بدون محدودیت - هر سایز و دسته‌ای می‌تواند انتخاب کند (همانند قبل)

### امتیاز (score)
- مجموع امتیاز همه بازی‌ها (cumulative)
- در localStorage + سرور ذخیره می‌شود
- با `max` بین local و server ادغام می‌شود

### لیگ (trophies)
- معیار پرستیژ و رقابت جدی
- فقط برای Quick Match / Battle mode استفاده می‌شود
- برای نمایش در لیدربورد و پروفایل
